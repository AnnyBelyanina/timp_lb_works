# Модульное тестирование шифра Гронсвельда (modAlphaCipher)

## Описание
Проект содержит модульные тесты для русскоязычного шифра Гронсфельда, разработанного в лабораторных работах №1 и №2. 

## Зависимости
- Компилятор C++ (g++) с поддержкой стандарта C++17
- Библиотека UnitTest++

#Сборка
make

#Запуск тестов
./test_modAlphaCipher
или
make test
